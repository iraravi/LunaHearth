# ADR-043: Pantry photos with explicit review

The user requested a pantry item list from a kitchen photo alongside receipt import. Pantry → Add from kitchen photo provides a photo picker and a just-in-time camera, an editable proposed list, optional amounts and pack expiry, and explicit selection/save. The receipt shortcut opens the existing expense/purchase workflow. Kitchen observations do not complete shopping, record expenses, clear low stock or increment existing quantities.

On iOS 27 with available Apple Intelligence, a session explicitly bound to SystemLanguageModel.default accepts a bounded, orientation-correct image and returns up to 50 grocery names. All proposals begin unselected. No counts, dates or safety claims are generated. Label text is untrusted; the prompt excludes ingredient lists as separate packs. This cannot guarantee recognition accuracy. Older/unavailable/failed models use Vision OCR with whole-label pantry-catalog matching, clearly labelled as a narrower fallback. There are no starter-list substitutions masquerading as detections. Empty results, errors, cancel and manual names remain usable.

Photo bytes and thumbnail previews are transient, not persisted, logged, backed up or sent to CloudKit. Confirmed InventoryItem records use existing local-first optional household sync. No schema, ownership or network architecture changes. No cloud AI or new dependencies. PhotosPicker avoids broad library access; the camera checks authorization only on user action. A household change dismisses the scoped review. Cancellation and rescan discard stale results.

A single repository transaction validates all selected drafts before writes, rechecks household and current aliases, and skips active existing entries and within-batch duplicates. Existing stock remains unchanged because a photo is not evidence of an additional purchase. The saved count reports actual inserted items. User-entered amount/expiry alone are persisted; omitted values stay unknown. Read-only/recovery protections remain in the shared commit path.

Apple API references: https://developer.apple.com/documentation/foundationmodels/analyzing-images-with-multimodal-prompting and the installed iOS 27 FoundationModels SDK interface. Deployment remains iOS 18. Unit tests cover aliases, bounds, conservative OCR mapping, atomicity, household checks, duplicate re-import and user-entered metadata. A synthetic image exercises actual Vision OCR; device image-model quality still requires real shelf-photo evaluation.
