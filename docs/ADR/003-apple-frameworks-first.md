# ADR-003: Apple-frameworks-first dependency policy

**Status:** Accepted

Use SwiftUI, SwiftData, CloudKit, EventKit, Vision, RoomPlan, Foundation Models, WidgetKit, App Intents, UserNotifications, StoreKit, OSLog, and other first-party APIs before third-party libraries.

Runtime third-party packages require a new ADR.

XcodeGen is allowed as a development-only generator.
