# Roadmap

## Stage A — Local household core
**Outcome:** useful with no iCloud and no AI.

- onboarding
- members
- Today
- family events
- tasks
- groceries
- meals basic
- rooms/assets
- warranties/maintenance

## Stage B — Capture and Apple integrations
- EventKit display/export
- local notifications
- document vault
- Vision OCR
- appliance/receipt/flyer extraction

## Stage C — Private family collaboration
- explicit CloudKit custom-zone sync
- CKShare invite/accept/manage
- offline conflict handling
- optional document CKAsset sync

## Stage D — On-device intelligence
- natural-language Quick Add
- multimodal structured extraction
- household search/answers grounded in local data

## Stage E — Home spatial experience
- RoomPlan scanning
- multi-room structure where supported
- adaptive/large-screen Home navigator

## Stage F — System surfaces
- WidgetKit
- interactive widgets
- App Intents/Siri
- Apple Watch companion if validated

## Stage G — Business/release maturity
- StoreKit 2
- export/backup
- localization
- advanced accessibility
- App Store/legal/privacy release gates

## Not on roadmap without validation
- custom cloud/backend
- Android/web
- social network
- ads
- child accounts
- location tracking
- remote AI APIs
