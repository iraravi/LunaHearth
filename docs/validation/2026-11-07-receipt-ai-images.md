# Receipt AI, optional images and clear categories

Requested additions to the live-v2 fixes, developed on codex/receipt-calendar-reliability. No release or upload.

- On-device receipt-to-shopping AI is a separate comparison mode with its own domain protocol. It uses the existing aiDuplicates capability/operational switch, bounded name-only batches and explicit confirmation. A transient name/ID snapshot is validated at save; no persistence schema or CloudKit mapping change. Existing offline matches remain. Physical model quality is not proven by simulator tests.
- Optional receipt image copies are off by default. Review previews use a 1600-pixel JPEG at quality 0.65, capped at 1 MB per page and four pages. Compression and protected atomic file I/O run on an actor. Original metadata is not copied. A failed image preparation does not invalidate OCR results and disables keeping an incomplete copy. No images load during app startup or purchase-list rendering. Copies load only when opening Saved receipt image.
- Local image files are stored separately from SwiftData, keyed by locally generated household/purchase UUIDs. They are not CloudKit attachments, not included in .nlbackup exports, and may be included in device backups. These limitations are disclosed at opt-in and in app privacy copy. Purchase detail permits explicit removal of only the copy. Files remain on this device until removed or app data is removed; no automatic retention deletion is introduced. Expense-only scans without selected purchase items cannot retain an image because no purchase-history record exists to reopen it. Image-save failure leaves the successful financial/pantry transaction intact and reports the partial result.
- Pantry now includes Meat & seafood. Previously AI was offered no meat category at all; known meat names previously fell through to AI/Other. Known meat classification takes precedence over an incorrect AI hint. Plant/style labels are not asserted to be meat; goat milk and chicken eggs remain dairy/eggs, and chicken masala remains spices. This is presentation taxonomy, not food safety or ingredient identity.
- Global native switches use an explicit green tint and visible On/Off labels, preserving native switch accessibility semantics. No private UI APIs or new dependencies.

Affected data: ReceiptLine transient review state; GroceryItem matching; PurchaseEntry association; optional local compressed image files. No migration and no existing records deleted or merged.
